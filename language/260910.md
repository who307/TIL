## 핵심 내용(코드)

### 화살표 함수 (Arrow Function)

```javascript
/**
 * 화살표 함수(Arrow Function)
 * function 키워드 대신 => 화살표를 사용해 함수를 간결하게 정의한다.
 * 본문이 단일 표현식이면 중괄호와 return 키워드를 생략할 수 있다.
 * 객체 리터럴을 바로 반환할 때는 실행문과의 혼동을 막기 위해 소괄호 ()로 감싸주어야 한다.
 */

// 단일 표현식 축약 표현
const square = (x) => x * x;
console.log(square(3)); // 9

// 중괄호 본문 사용 시 반드시 return 키워드 명시 필요
const calculateSquare = (x) => {
    return x * x;
};

// 객체 리터럴 반환 시 소괄호 () 사용
const createUser = (id, name) => ({ id: id, name: name });
console.log(createUser(1, "홍길동")); // { id: 1, name: '홍길동' }

// 콜백 함수로 화살표 함수 전달
function calculate(value, operation) {
    return operation(value);
}
console.log(calculate(3, (number) => number * number)); // 9

```

### 배열 기초 및 복사 (Array & Copy)

```javascript
/**
 * 배열(Array) 및 복사 방식
 * 관련 있는 값들을 하나의 목록으로 관리하며 0부터 시작하는 인덱스를 갖는다.
 * 스프레드 문법([...arr])을 통한 얕은 복사 및 structuredClone()을 통한 깊은 복사를 제공한다.
 */

const fruits = ["바나나", "복숭아", "키위"];

// 배열 확인 및 순회
console.log(Array.isArray(fruits)); // true

for (let item of fruits) {
    console.log(item);
}

// 1차원 배열의 얕은 복사 (독립적인 새 배열 생성)
const shallowCopy = [...fruits];

// 깊은 복사 (내부의 중첩된 객체/배열까지 완벽하게 독립적인 복사본 생성)
const deepCopy = structuredClone(fruits);

```

### 배열 기본 조작 메서드 및 중복 제거

```javascript
/**
 * 배열 기본 메서드
 * - push / pop: 배열 끝에 요소를 추가 / 제거
 * - unshift / shift: 배열 맨 앞에 요소를 추가 / 제거
 * - indexOf / includes: 요소의 인덱스 검색 / 존재 여부 확인 (Boolean)
 */

const foods = ["짜장면", "짬뽕", "볶음밥"];

foods.push("탕수육"); // 배열 끝에 추가
foods.pop();        // 배열 끝 요소 제거 ("탕수육")

foods.unshift("유산슬"); // 배열 맨 앞에 추가
foods.shift();          // 배열 맨 앞 요소 제거 ("유산슬")

const animals = ["고양이", "강아지", "토끼", "고양이"];
console.log(animals.indexOf("고양이")); // 0 (없으면 -1 반환)
console.log(animals.includes("사슴"));  // false

// Set과 스프레드 연산자를 활용한 중복 요소 제거
const uniqueArr = [...new Set(animals)];
console.log(uniqueArr); // ["고양이", "강아지", "토끼"]

```

### 배열 순회 및 변환 (`forEach`, `map`)

```javascript
/**
 * 배열 고차 함수: forEach & map
 * - forEach: 각 요소를 순회하며 콜백 함수를 실행 (반환값은 undefined)
 * - map: 각 요소를 콜백 함수 반환값으로 변환한 "새로운 배열" 생성 (원본 유지)
 */

const students = [
    { name: "홍길동", score: 90 },
    { name: "권판다", score: 80 },
    { name: "유관순", score: 70 },
];

// forEach: 순회하며 단순 작업 수행
students.forEach((student, index) => {
    console.log(`${index + 1}번째 이름: ${student.name}`);
});

// map: 기존 데이터를 기반으로 새로운 데이터 배열 생성
const adjustedScores = students.map((student) => {
    return {
        name: student.name,
        score: student.score + 5,
    };
});
console.log(adjustedScores);

```

### 배열 조건 탐색 및 검사 (`filter`, `find`, `some`, `every`)

```javascript
/**
 * 배열 고차 함수: 조건 탐색 및 검사
 * - filter: 조건을 만족하는 모든 요소를 새 배열로 반환
 * - find: 조건을 만족하는 첫 번째 요소를 반환 (없으면 undefined)
 * - some: 조건에 참인 요소가 최소 1개 이상 존재하는지 확인 (Boolean)
 * - every: 모든 요소가 조건을 만족하는지 확인 (Boolean)
 */

const students = [
    { name: "홍길동", score: 90 },
    { name: "권판다", score: 80 },
    { name: "유관순", score: 85 },
];

// filter: 85점 이상인 학생 목록 배열 생성
const highScorers = students.filter((student) => student.score >= 85);

// find: 85점 이상인 첫 번째 학생 검색 (없을 경우를 대비해 ?. 사용 가능)
const firstHighScorer = students.find((student) => student.score >= 85);
console.log(firstHighScorer?.name); // 홍길동

const missingStudent = students.find((student) => student.score >= 100);
console.log(missingStudent?.name); // undefined (에러 없이 안전하게 평가)

// some & every
const hasHighScorer = students.some((student) => student.score >= 85); // true
const allHighScorer = students.every((student) => student.score >= 80); // true

```

### 배열 정렬 및 누적 연산 (`sort`, `reduce`)

```javascript
/**
 * 배열 고차 함수: sort & reduce
 * - sort: 원본 배열을 직접 변경하여 정렬 (숫자 정렬 시 비교 함수 필요)
 * - reduce: 배열의 요소를 순회하며 하나의 누적값을 생성
 */

const numbers = [3, 1, 4, 12, 8];

// 숫자 정렬 (a - b: 오름차순, b - a: 내림차순)
// sort()는 원본 배열을 직접 수정(Mutation)함에 유의
numbers.sort((a, b) => b - a);
console.log(numbers); // [12, 8, 4, 3, 1]

const amounts = [1000, 2000, 5000, 200, 400];

// reduce를 통한 합계 누적 (두 번째 인자는 초기값 0)
const total = amounts.reduce((sum, current) => sum + current, 0);
console.log(total); // 8600

```

### `Math` 표준 빌트인 객체

```javascript
/**
 * Math 표준 빌트인 객체
 * 수학 계산 기능을 제공하는 정적 객체로 생성자(new) 없이 Math.메서드() 형태로 사용
 */

// 소수점 처리
console.log(Math.round(3.6)); // 4 (반올림)
console.log(Math.floor(3.6)); // 3 (내림)
console.log(Math.ceil(3.6));  // 4 (올림)

// Math.random()과 Math.floor()를 활용한 배열 내 무작위 요소 추출
const menus = ["비빔밥", "라면", "뚝배기불고기", "햄버거"];
const menuIndex = Math.floor(Math.random() * menus.length);

console.log("선택 인덱스:", menuIndex);
console.log("추천 메뉴:", menus[menuIndex]);

```

## 느낀 점

* 화살표 함수 본문을 중괄호 `{}`로 작성할 때 `return`을 명시하지 않으면 `undefined`가 반환되거나, 객체 리터럴 반환 시 `()` 소괄호로 감싸지 않아 생기는 실수를 직접 확인하며 정교한 화살표 함수 문법의 중요성을 실감함
* 배열을 다룰 때 `sort`처럼 원본 배열을 직접 변경(Mutation)하는 메서드와 `map`, `filter`, `reduce`처럼 불변성을 유지하며 새로운 배열/값을 반환하는 순수 함수 형태의 고차 함수 메서드를 명확히 구분하여 사용해야 함을 체감함
* `find` 메서드는 일치하는 요소가 없을 때 `undefined`를 반환하므로, 이전 시간에 배운 옵셔널 체이닝 연산자(`?.`)와 함께 조합하여 런타임 에러(`TypeError`) 없이 안전한 코드 구조를 작성하는 실무 패턴을 익힘
* `Set`과 스프레드 문법을 조합하여 배열 중복을 한 줄로 제거하는 간단하고 유용한 패턴과 함께, `structuredClone`을 활용한 완벽한 깊은 복사(Deep Copy) 방법을 정리할 수 있었음
