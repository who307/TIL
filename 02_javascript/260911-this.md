## 1. Date 객체

* **한 줄 비유**: `Date`는 컴퓨터 안에 있는 **달력 + 시계**임. `new Date()`라고 부르면 "지금 이 순간"이 찍힌 달력 한 장을 받음.
* **주의**: `getMonth()`는 월을 **0부터** 셈. 1월이 0, 12월이 11이라 사람이 읽으려면 **+1**을 해야 함.

```javascript
/**
 * Date 객체
 * 날짜와 시간을 표현하는 빌트인 객체로 new Date()로 생성한다.
 * getMonth()는 0부터 시작(0: 1월)하므로 +1 처리가 필요하다.
 */

const now = new Date();
console.log(now);

// 한국어 형식 표시
console.log("한국어 표시:", now.toLocaleString("ko-KR", { timeZone: "Asia/Seoul" }));

const year = now.getFullYear();
const month = now.getMonth() + 1; // 0부터 시작하므로 +1
const date = now.getDate();

console.log(`${year}년 ${month}월 ${date}일`);

```

* **한 줄씩 보기** (예: 2026년 9월 11일 오후 3시에 실행)
  * `new Date()` → 지금 시각을 담은 객체. 그대로 출력하면 `2026-09-11T06:00:00.000Z`처럼 세계 표준시(UTC) 기준으로 보임.
  * `toLocaleString("ko-KR", { timeZone: "Asia/Seoul" })` → 한국 사람이 읽는 형식, 한국 시간으로 바꿈 → `2026. 9. 11. 오후 3:00:00`
  * `getFullYear()` → `2026`
  * `getMonth() + 1` → `getMonth()`는 8(9월) → `+1` → `9`
  * `getDate()` → 그 달의 며칠인지 → `11`
  * 최종 출력 → `2026년 9월 11일`

## 2. 화살표 함수와 `this`

* **`this`**: "**지금 나를 부른 주인**"을 가리키는 단어.
* **일반 함수의 `this`**: **어떻게 불렸는지**에 따라 바뀜. `theater.showMovieList()`처럼 점 앞에 주인이 있으면 그 주인이 `this`임. 그런데 콜백으로 넘겨져서 주인 없이 불리면 `this`를 잃어버림(`undefined` 또는 전역 객체).
* **화살표 함수의 `this`**: 자기 `this`가 **없음**. 대신 자기가 **적혀 있는 바깥 함수의 `this`** 를 그대로 빌려 씀(Lexical this). 엄마 손을 꼭 잡고 다니는 아이처럼, 어디로 불려가도 바깥의 `this`를 따라감.

```javascript
/**
 * 화살표 함수의 this
 * 일반 함수는 호출 방식에 따라 this가 동적으로 바인딩되지만,
 * 화살표 함수는 자신만의 this를 가지지 않고 상위 스코프의 this를 정적으로 바인딩(Lexical this)한다.
 */

const theater = {
    store: "청량리역점",
    titles: ["오딧세이", "옵세션"],

    showMovieList: function () {
        // 일반 함수 콜백: this가 전역 객체(또는 undefined)를 가리켜 this.store 참조 실패
        // 화살표 함수 콜백: 상위 스코프(showMovieList)의 this(theater)를 그대로 참조함
        this.titles.forEach((title) => {
            console.log(this.store + ": " + title); // 청량리역점: 오딧세이 ...
        });
    },
};

theater.showMovieList();

```

* **따라가기**
  1. `theater.showMovieList()` → 점 앞의 주인이 `theater` → `showMovieList` 안의 `this`는 `theater`.
  2. `this.titles` → `["오딧세이", "옵세션"]`. `forEach`가 칸마다 콜백을 부름.
  3. 콜백은 **화살표 함수**라 자기 `this`가 없음 → 바깥 `showMovieList`의 `this`(theater)를 빌림.
  4. `this.store` → `"청량리역점"` → `청량리역점: 오딧세이`, `청량리역점: 옵세션` 출력.
  * 만약 콜백을 `function (title) { ... }`으로 썼다면 → `forEach`가 주인 없이 부르므로 `this`를 잃음 → `this.store`가 `undefined`가 되거나 에러가 남.

## 3. 클래스 (Class)

* **한 줄 비유**: 지난번 배운 생성자 함수(붕어빵 틀)를 **더 깔끔한 모양으로 쓰는 문법**임. 기능은 같고 겉모습만 정리된 것이라 "문법적 설탕(Syntactic Sugar)"이라고 부름.
* **구성**
  * `constructor(...)`: `new`로 만들 때 **처음 한 번** 실행되어 칸을 채우는 함수.
  * 메서드(`getInfo()`): 클래스 안에 쓴 메서드는 **프로토타입**에 한 번만 저장되고, 모든 인스턴스가 **같이 씀**. 생성자 함수에서 `this.getInfo = function...`으로 쓰면 인스턴스마다 함수가 복사되는 것과 다름.

```javascript
/**
 * ES6 Class
 * 생성자 함수를 깔끔하게 작성할 수 있는 문법적 설탕(Syntactic Sugar)
 * constructor()로 인스턴스를 초기화하며, 메서드는 프로토타입(Student.prototype)에 등록되어 공유된다.
 */

class Student {
    constructor(name, score) {
        this.name = name;
        this.score = score;
    }

    // 프로토타입 메서드로 공유
    getInfo() {
        return `${this.name}:${this.score}점`;
    }
}

const student1 = new Student("홍길동", 80);
const student2 = new Student("유관순", 90);

console.log(student1.getInfo()); // 홍길동:80점
console.log(student2.getInfo()); // 유관순:90점

```

* **따라가기**
  1. `new Student("홍길동", 80)` → 빈 객체 생성 → `constructor` 실행 → `{ name: "홍길동", score: 80 }`
  2. `student1.getInfo()` → `student1`에는 `getInfo`가 없음 → 프로토타입(`Student.prototype`)에서 찾음 → `this`는 `student1` → `홍길동:80점`
  3. `student2.getInfo()` → **같은** `getInfo` 함수를 쓰지만 `this`가 `student2` → `유관순:90점`

## 4. 이터러블과 `for...of`

* **이터러블(Iterable)**: 값을 **순서대로 하나씩 꺼낼 수 있는** 것. 배열, 문자열이 대표적임. 컨베이어 벨트 위의 물건처럼 차례로 나옴.
* **`for...of`**: 이터러블에서 **값을 하나씩** 꺼내 반복함. 번호(인덱스)를 신경 쓰지 않아도 됨.
  * 헷갈리기 쉬운 것: `for...in`은 객체의 **키**를 돌고, `for...of`는 이터러블의 **값**을 돎.

```javascript
/**
 * 이터러블(Iterable) & for...of
 * 순서대로 값을 꺼낼 수 있는 객체(배열, 문자열 등)를 이터러블이라 한다.
 * for...of 문을 통해 인덱스 없이 요소의 값에 직접 접근하여 순회할 수 있다.
 */

const fruits = ["🍎", "🍇", "🍌"];

for (const item of fruits) {
    console.log("for...of 요소:", item);
}

const message = "안녕";
for (const character of message) {
    console.log("글자:", character);
}

```

* **실행 결과**
  * 배열 → `for...of 요소: 🍎`, `for...of 요소: 🍇`, `for...of 요소: 🍌`
  * 문자열 → 글자 하나하나가 값 → `글자: 안`, `글자: 녕`

## 5. 스프레드 문법과 Rest 파라미터

* 둘 다 `...` 기호를 쓰지만 **하는 일이 반대**임.

| 이름 | 쓰는 자리 | 하는 일 | 비유 |
| :--- | :--- | :--- | :--- |
| **Spread** | 배열·객체 안, 함수를 **부를 때** 인수 자리 | 묶음을 **낱개로 펼침** | 과자 봉지를 뜯어 접시에 쏟기 |
| **Rest** | 함수를 **만들 때** 매개변수 자리 | 낱개를 **배열 하나로 모음** | 흩어진 과자를 봉지에 주워 담기 |

```javascript
/**
 * Spread Syntax & Rest Parameter
 * - Spread(...): 배열/객체 리터럴이나 함수 인수 자리에서 요소를 개별 값으로 펼친다.
 * - Rest(...): 함수 매개변수 자리에서 정해지지 않은 가변 인수들을 하나의 배열로 모아준다.
 */

const scores = [80, 95, 70];

// 1. Spread 문법으로 배열 요소 펼치기
console.log(Math.max(...scores)); // 95

// 2. 객체 펼치기 및 얕은 복사/프로퍼티 덮어쓰기
const student = { name: "홍길동", score: 80 };
const updatedStudent = { ...student, score: 90 };
console.log(updatedStudent); // { name: '홍길동', score: 90 }

// 3. Rest 파라미터로 가변 인수 모으기
function printTotal(label, ...values) {
    let total = 0;
    for (const value of values) {
        total += value;
    }
    console.log(label, total);
}

const prices = [1000, 2000, 3000];
printTotal("합계:", ...prices); // 합계: 6000

```

* **따라가기**
  * `Math.max(...scores)` → `Math.max`는 배열이 아니라 낱개 숫자를 받음 → `...`가 펼쳐서 `Math.max(80, 95, 70)` → `95`
  * `{ ...student, score: 90 }`
    1. `...student`가 칸을 펼침 → `{ name: "홍길동", score: 80 }`
    2. 뒤에 `score: 90`이 오면서 같은 이름의 칸을 **덮어씀** → `{ name: "홍길동", score: 90 }`
    3. `student` 원본은 그대로 80임 (새 객체를 만든 것이므로).
  * `printTotal("합계:", ...prices)`
    1. 부르는 쪽의 `...prices`(Spread) → `printTotal("합계:", 1000, 2000, 3000)`
    2. 받는 쪽: 첫 번째 `"합계:"`는 `label`에, **나머지 전부**는 `...values`(Rest)가 배열로 모음 → `values = [1000, 2000, 3000]`
    3. 반복하며 더함: 0 → 1000 → 3000 → 6000
    4. 출력 → `합계: 6000`

## 6. 구조 분해 할당 (Destructuring Assignment)

* **한 줄 비유**: 택배 상자를 뜯어서 물건을 **각자 자기 자리에 바로 꺼내 놓는 것**. 상자째 들고 다니며 `상자.물건`이라고 매번 부르지 않아도 됨.
* **배열 구조 분해**: **순서**대로 꺼냄 → `const [a, b] = [1, 2]` → a=1, b=2
* **객체 구조 분해**: **키 이름**으로 꺼냄 → `const { name } = obj` → `obj.name`을 `name` 변수에
  * `name: learnerName` → `name` 칸을 꺼내되 **변수 이름은 `learnerName`** 으로 바꿈.
  * `job = "학생"` → `job` 칸이 없으면 **기본값** "학생"을 씀.

```javascript
/**
 * 구조 분해 할당
 * 배열의 요소나 객체의 속성을 해체하여 개별 변수에 손쉽게 담는 표현식
 */

// 1. 배열 구조 분해 할당 (순서 기준)
const [first, ...others] = ["유관순", "장보고", "이순신"];
console.log(first);  // "유관순"
console.log(others); // ["장보고", "이순신"]

// 2. 객체 구조 분해 할당 (키 이름 기준, 기본값 및 변수명 변경)
const learner = { name: "유관순", age: 16 };
const { name: learnerName, job = "학생" } = learner;
console.log(learnerName, job); // "유관순", "학생"

// 3. 함수 매개변수 및 중첩 객체 구조 분해 할당
const product = {
    name: "노트북",
    price: 2000000,
    spec: { cpu: "i7", ram: "16GB" },
};

function printProduct({ name, price, spec: { cpu }, producer = "삼성" }) {
    console.log(`상품명: ${name}, 가격: ${price}, CPU: ${cpu}, 제조사: ${producer}`);
}
printProduct(product);

// 4. 배열 고차 함수 콜백에서의 활용
const products = [{ name: "키보드", price: 50000 }, { name: "마우스", price: 30000 }];
const productNames = products.map(({ name }) => name);
console.log(productNames); // ["키보드", "마우스"]

```

* **따라가기**
  * `[first, ...others]` → 0번 칸 "유관순"은 `first`에, 나머지는 Rest로 모아 `others = ["장보고", "이순신"]`
  * `{ name: learnerName, job = "학생" } = learner`
    * `learner.name`("유관순") → 변수 `learnerName`에 저장.
    * `learner.job`은 없음 → 기본값 → `job = "학생"`
    * 출력 → `유관순 학생`
  * `printProduct(product)` → 함수가 받는 순간 매개변수 자리에서 바로 분해함
    * `name` → "노트북", `price` → 2000000
    * `spec: { cpu }` → `spec` 칸 안으로 **한 번 더 들어가** `cpu`만 꺼냄 → "i7"
    * `producer`는 없음 → 기본값 "삼성"
    * 출력 → `상품명: 노트북, 가격: 2000000, CPU: i7, 제조사: 삼성`
  * `products.map(({ name }) => name)` → 칸마다 객체를 받아 `name`만 꺼내 돌려줌 → `["키보드", "마우스"]`

## 느낀 점

* `Date` 객체 다룰 때 `getMonth()` 메서드가 0부터 시작한다는 점을 꼭 유의해서 `+1` 처리를 해야 함을 복습함
* 객체 내부 메서드의 콜백 함수로 일반 함수를 전달했을 때 `this`가 끊기는 현상을 겪으면서, 외부 상위 스코프의 `this`를 정적으로 참조하는 화살표 함수의 `Lexical this` 특성이 왜 유용한지 명확히 깨달음
* 기존 생성자 함수 기반의 객체 생성 방식과 비교해 ES6 `class` 키워드를 사용하니 `constructor`와 프로토타입 메서드의 구분이 한눈에 보여 한층 직관적이고 깔끔한 객체지향 코드를 작성할 수 있음을 체감함
* 동일한 `...` 기호를 사용하지만 호출 인자나 리터럴에 쓰여 요소를 펼쳐주는 `Spread` 연산자와, 매개변수에 쓰여 가변 인자들을 배열로 묶어주는 `Rest` 파라미터의 역할 차이를 정확히 정리함
* 구조 분해 할당을 함수 매개변수나 배열 메서드 콜백(`map(({ name }) => ...)`)에서 활용하면, 불필요한 중간 변수 선언 없이 필요한 프로퍼티만 깔끔하게 꺼내 쓸 수 있어 코드의 가독성이 대폭 향상됨을 배움
