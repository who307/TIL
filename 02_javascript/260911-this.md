## 핵심 내용(코드)

### Date 객체

```javascript
/**
 * Date 객체
 * 날짜와 시간을 표현하는 빌트인 객체로 new Date()로 생성한다.
 * getMonth()는 0부터 시작(0: 1월)하므로 +1 처리가 필요하다.
 */

const now = new Date();
console.log(now);

// 한국어 형식 표시
console.log("한국어 표시:", now.toLocaleString("ko-KR", { timeZone: "Asia/Seoul" }));

const year = now.getFullYear();
const month = now.getMonth() + 1; // 0부터 시작하므로 +1
const date = now.getDate();

console.log(`${year}년 ${month}월 ${date}일`);

```

### 화살표 함수와 `this` 바인딩

```javascript
/**
 * 화살표 함수의 this
 * 일반 함수는 호출 방식에 따라 this가 동적으로 바인딩되지만,
 * 화살표 함수는 자신만의 this를 가지지 않고 상위 스코프의 this를 정적으로 바인딩(Lexical this)한다.
 */

const theater = {
    store: "청량리역점",
    titles: ["오딧세이", "옵세션"],

    showMovieList: function () {
        // 일반 함수 콜백: this가 전역 객체(또는 undefined)를 가리켜 this.store 참조 실패
        // 화살표 함수 콜백: 상위 스코프(showMovieList)의 this(theater)를 그대로 참조함
        this.titles.forEach((title) => {
            console.log(this.store + ": " + title); // 청량리역점: 오딧세이 ...
        });
    },
};

theater.showMovieList();

```

### 클래스 (Class)

```javascript
/**
 * ES6 Class
 * 생성자 함수를 깔끔하게 작성할 수 있는 문법적 설탕(Syntactic Sugar)
 * constructor()로 인스턴스를 초기화하며, 메서드는 프로토타입(Student.prototype)에 등록되어 공유된다.
 */

class Student {
    constructor(name, score) {
        this.name = name;
        this.score = score;
    }

    // 프로토타입 메서드로 공유
    getInfo() {
        return `${this.name}:${this.score}점`;
    }
}

const student1 = new Student("홍길동", 80);
const student2 = new Student("유관순", 90);

console.log(student1.getInfo()); // 홍길동:80점
console.log(student2.getInfo()); // 유관순:90점

```

### 이터러블과 `for...of`

```javascript
/**
 * 이터러블(Iterable) & for...of
 * 순서대로 값을 꺼낼 수 있는 객체(배열, 문자열 등)를 이터러블이라 한다.
 * for...of 문을 통해 인덱스 없이 요소의 값에 직접 접근하여 순회할 수 있다.
 */

const fruits = ["🍎", "🍇", "🍌"];

for (const item of fruits) {
    console.log("for...of 요소:", item);
}

const message = "안녕";
for (const character of message) {
    console.log("글자:", character);
}

```

### 스프레드 문법과 Rest 파라미터

```javascript
/**
 * Spread Syntax & Rest Parameter
 * - Spread(...): 배열/객체 리터럴이나 함수 인수 자리에서 요소를 개별 값으로 펼친다.
 * - Rest(...): 함수 매개변수 자리에서 정해지지 않은 가변 인수들을 하나의 배열로 모아준다.
 */

const scores = [80, 95, 70];

// 1. Spread 문법으로 배열 요소 펼치기
console.log(Math.max(...scores)); // 95

// 2. 객체 펼치기 및 얕은 복사/프로퍼티 덮어쓰기
const student = { name: "홍길동", score: 80 };
const updatedStudent = { ...student, score: 90 };
console.log(updatedStudent); // { name: '홍길동', score: 90 }

// 3. Rest 파라미터로 가변 인수 모으기
function printTotal(label, ...values) {
    let total = 0;
    for (const value of values) {
        total += value;
    }
    console.log(label, total);
}

const prices = [1000, 2000, 3000];
printTotal("합계:", ...prices); // 합계: 6000

```

### 구조 분해 할당 (Destructuring Assignment)

```javascript
/**
 * 구조 분해 할당
 * 배열의 요소나 객체의 속성을 해체하여 개별 변수에 손쉽게 담는 표현식
 */

// 1. 배열 구조 분해 할당 (순서 기준)
const [first, ...others] = ["유관순", "장보고", "이순신"];
console.log(first);  // "유관순"
console.log(others); // ["장보고", "이순신"]

// 2. 객체 구조 분해 할당 (키 이름 기준, 기본값 및 변수명 변경)
const learner = { name: "유관순", age: 16 };
const { name: learnerName, job = "학생" } = learner;
console.log(learnerName, job); // "유관순", "학생"

// 3. 함수 매개변수 및 중첩 객체 구조 분해 할당
const product = {
    name: "노트북",
    price: 2000000,
    spec: { cpu: "i7", ram: "16GB" },
};

function printProduct({ name, price, spec: { cpu }, producer = "삼성" }) {
    console.log(`상품명: ${name}, 가격: ${price}, CPU: ${cpu}, 제조사: ${producer}`);
}
printProduct(product);

// 4. 배열 고차 함수 콜백에서의 활용
const products = [{ name: "키보드", price: 50000 }, { name: "마우스", price: 30000 }];
const productNames = products.map(({ name }) => name);
console.log(productNames); // ["키보드", "마우스"]

```

## 느낀 점

* `Date` 객체 다룰 때 `getMonth()` 메서드가 0부터 시작한다는 점을 꼭 유의해서 `+1` 처리를 해야 함을 복습함


* 객체 내부 메서드의 콜백 함수로 일반 함수를 전달했을 때 `this`가 끊기는 현상을 겪으면서, 외부 상위 스코프의 `this`를 정적으로 참조하는 화살표 함수의 `Lexical this` 특성이 왜 유용한지 명확히 깨달음


* 기존 생성자 함수 기반의 객체 생성 방식과 비교해 ES6 `class` 키워드를 사용하니 `constructor`와 프로토타입 메서드의 구분이 한눈에 보여 한층 직관적이고 깔끔한 객체지향 코드를 작성할 수 있음을 체감함


* 동일한 `...` 기호를 사용하지만 호출 인자나 리터럴에 쓰여 요소를 펼쳐주는 `Spread` 연산자와, 매개변수에 쓰여 가변 인자들을 배열로 묶어주는 `Rest` 파라미터의 역할 차이를 정확히 정리함


* 구조 분해 할당을 함수 매개변수나 배열 메서드 콜백(`map(({ name }) => ...)`)에서 활용하면, 불필요한 중간 변수 선언 없이 필요한 프로퍼티만 깔끔하게 꺼내 쓸 수 있어 코드의 가독성이 대폭 향상됨을 배움
