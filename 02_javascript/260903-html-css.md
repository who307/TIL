## 1. HTML과 CSS는 각각 무슨 일을 하나

* **한 줄 비유**: 웹 페이지를 집이라고 하면 **HTML은 뼈대(벽·방·문)**, **CSS는 인테리어(벽지 색·가구 배치)** 임.
* **HTML (HyperText Markup Language)**: `<태그>`로 내용을 감싸서 "이건 제목", "이건 문단"이라고 **역할을 표시**하는 언어.
  * 예: `<h1>오늘의 일기</h1>` → 브라우저가 "아, 이게 제일 큰 제목이구나" 하고 크게 보여줌.
* **CSS (Cascading Style Sheets)**: HTML로 만든 요소에 **색, 크기, 글꼴, 간격** 같은 모양을 입히는 언어.

---

## 2. 시맨틱 태그 (Semantic Tag)

* **한 줄 비유**: 상자마다 "부엌용품", "옷", "책"이라고 **이름표를 붙여두는 것**과 같음.
* **뜻**: 생김새가 아니라 **의미**를 알려주는 태그. `<div>`는 아무 의미 없는 상자이고, `<header>`는 "이건 머리말 영역"이라는 의미가 있음.
* **왜 필요한가**
  1. 코드를 읽는 사람이 구조를 바로 알아봄 (`<nav>`면 메뉴구나).
  2. 검색 엔진이 페이지 내용을 더 잘 이해함.
  3. 화면을 읽어주는 프로그램(스크린 리더)이 시각장애인에게 구조를 정확히 안내할 수 있음.

| 태그 | 의미 |
| :--- | :--- |
| `<header>` | 페이지나 구역의 머리말 (로고, 제목) |
| `<nav>` | 다른 페이지로 가는 메뉴 모음 |
| `<main>` | 페이지의 핵심 내용 (한 페이지에 하나) |
| `<section>` | 주제별로 묶은 구역 |
| `<article>` | 그 자체로 완결된 글 (블로그 글 하나) |
| `<footer>` | 꼬리말 (저작권, 연락처) |

## 3. CSS 선택자 (Selector)

* **선택자**: "어떤 요소에 스타일을 입힐지" **골라내는 방법**. 반 친구들 중 "안경 쓴 사람", "3번 학생"처럼 대상을 지목하는 것과 같음.
* CSS 한 덩어리는 `선택자 { 속성: 값; }` 모양임. 예: `p { color: #333; }` → "모든 `<p>`의 글자색을 #333으로".

```css
/* 태그 선택자 */
p {
  color: #333;
}

/* 클래스 선택자 */
.title {
  color: royalblue;
}

/* 아이디 선택자 */
#description {
  font-size: 18px;
}

/* 자손 선택자 */
main p {
  line-height: 1.6;
}

/* 여러 선택자에 동일한 스타일 적용 */
h1,
h2 {
  font-family: Arial, sans-serif;
}
```

* **한 줄씩 보기**
  * `p { color: #333; }` → 페이지에 있는 **모든** `<p>` 태그의 글자를 진한 회색(#333)으로 바꿈.
  * `.title { ... }` → 점(`.`)은 **클래스**라는 뜻. `class="title"`이 붙은 요소만 골라 파란색(royalblue)으로 바꿈. 클래스는 여러 요소에 같이 붙일 수 있음.
  * `#description { ... }` → 샵(`#`)은 **아이디**라는 뜻. `id="description"`인 요소 딱 하나만 골라 글자 크기를 18px로 바꿈. 아이디는 페이지에서 하나만 써야 함.
  * `main p { ... }` → 띄어쓰기는 "안에 들어 있는"이라는 뜻. `<main>` **안에 있는** `<p>`만 골라 줄 간격을 1.6배로 바꿈. `<main>` 밖의 `<p>`는 그대로임.
  * `h1, h2 { ... }` → 쉼표는 "그리고"라는 뜻. `<h1>`과 `<h2>` 둘 다 같은 글꼴(Arial, 없으면 sans-serif 계열)을 씀.

## 4. 선택자 우선순위

* **왜 필요한가**: 한 요소에 스타일이 여러 개 걸리면 브라우저는 **어느 것을 따를지** 정해야 함. 예를 들어 `<p class="title">`은 `p` 규칙(회색)과 `.title` 규칙(파랑) 둘 다에 해당함.
* **규칙**: 더 **구체적으로** 지목한 쪽이 이김. "학생 여러분"보다 "3번 학생"이라고 부른 말이 더 우선인 것과 같음.

`전체 선택자(*)` < `태그 선택자` < `클래스 선택자` < `아이디 선택자` < `인라인 스타일` < `!important`

* **따라가 보기**: `<p class="title">`
  1. `p` 규칙 → 글자색 #333 후보.
  2. `.title` 규칙 → 글자색 royalblue 후보.
  3. 클래스 선택자가 태그 선택자보다 우선순위가 높음 → **royalblue로 보임**.
* `인라인 스타일`은 태그에 직접 `style="color: red"`라고 쓴 것이고, `!important`는 "무조건 이걸 써!"라는 강제 표시임. `!important`는 남발하면 나중에 고치기 어려워서 꼭 필요할 때만 씀.

## 느낀 점

* HTML 기본 태그와 시맨틱 태그의 개념을 배우고 CSS 선택자를 사용해 원하는 요소에 스타일을 적용하는 방법을 익힘
* 스타일이 겹칠 때 "더 구체적으로 지목한 쪽이 이긴다"는 우선순위 규칙을 알고 나니, 스타일이 왜 안 먹히는지 원인을 찾는 기준이 생김
