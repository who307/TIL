## 핵심 내용(코드)

### React Element 생성 및 ReactDOM 렌더링

```javascript
/**
 * React.createElement("태그명", {속성 객체}, "자식 내용")
 * - 실제 DOM 노드가 아닌 React Element(자바스크립트 객체)를 생성한다.
 * - ReactDOM.createRoot()를 통해 root 노드를 지정하고 render()로 화면에 렌더링한다.
 */

// React 엘리먼트 생성
const greeting = React.createElement("h1", { className: "greeting" }, "안녕, 리액트!");

console.log(greeting); // React 객체 구조 출력

// DOM 렌더링
const root = ReactDOM.createRoot(document.getElementById("root"));
root.render(greeting);

```

### 컴포넌트(Component)와 JSX

```jsx
/**
 * 컴포넌트: UI를 재사용 가능한 독립 단위로 나눈 자바스크립트 함수/클래스 (이름은 대문자로 시작)
 * Fragment(<>...</>): 여러 태그를 반환할 때 단일 부모 노드로 감싸기 위한 빈 태그
 */

// 1. 클래스형 컴포넌트 (React.Component 상속 및 render() 필수 구현)
class TitleClass extends React.Component {
    render() {
        return React.createElement("h1", { className: "classComponent" }, "클래스형 컴포넌트입니다.");
    }
}

// 2. 함수형 컴포넌트 (createElement 방식 vs JSX 방식)
function OldWay() {
    return React.createElement(
        "div", null,
        React.createElement("h1", { className: "greeting" }, "createElement 방식"),
        React.createElement("p", null, "코드가 길고 복잡해요")
    );
}

function NewWay() {
    return (
        <>
            <h1 className="greeting">JSX 방식</h1>
            <p>HTML로 보여서 훨씬 직관적이다!!</p>
        </>
    );
}

function App() {
    return (
        <>
            <OldWay />
            <hr />
            <NewWay />
        </>
    );
}

ReactDOM.createRoot(document.getElementById("root")).render(<App />);

```

### JSX 문법 규칙

```jsx
/**
 * JSX 주요 규칙
 * 1. { } 중괄호 내부에 자바스크립트 변수 및 표현식 삽입 가능
 * 2. HTML 속성명은 카멜 케이스(camelCase) 사용 (class -> className, onclick -> onClick 등)
 * 3. 인라인 스타일은 객체 형태로 전달 (style={{ key: value }})
 * 4. 모든 태그는 단독 태그라도 반드시 닫아야 함 (<br />, <hr />)
 */

const user = {
    name: "홍길동",
    age: 20
};

function handleClick() {
    alert("버튼이 클릭되었습니다!");
}

const customStyle = {
    backgroundColor: "cornflowerblue",
    color: "white",
    padding: "10px",
    borderRadius: "5px"
};

function JsxRules() {
    return (
        <>
            {/* JSX 내부 주석 작성 방식 */}
            <h2>1. 표현식 사용</h2>
            <h3>이름: {user.name}</h3>

            <h2>2. 속성명 카멜 케이스 규칙</h2>
            <button className="my-button" onClick={handleClick}>
                클릭해보세요
            </button>

            <h2>3. 객체형 인라인 스타일</h2>
            <p style={customStyle}>
                커스텀 스타일이 적용되었습니다.
            </p>

            <h2>4. 셀프 클로징 태그 필수</h2>
            <br />
            <hr />
        </>
    );
}

ReactDOM.createRoot(document.getElementById("root")).render(<JsxRules />);

```

### 실시간 렌더링 동작

```jsx
/**
 * root.render() 함수를 호출할 때마다 매개변수로 전달된 엘리먼트 트리를 비교하여 갱신한다.
 */

function Clock() {
    return (
        <>
            <h1>실시간 시계</h1>
            <h2>현재 시간: {new Date().toLocaleTimeString()}</h2>
        </>
    );
}

const root = ReactDOM.createRoot(document.getElementById("root"));

function tick() {
    root.render(<Clock />);
}

// 1초마다 tick 함수 실행하여 시계 UI 갱신
setInterval(tick, 1000);

```

### Props와 `children`을 활용한 데이터 전달

```jsx
/**
 * Props (Properties)
 * - 부모 컴포넌트에서 자식 컴포넌트로 전달되는 읽기 전용(Read-only) 데이터
 * - 단방향 데이터 흐름 (부모 -> 자식)
 * - 구조 분해 할당 및 파라미터 기본값 지정 가능
 * - 컴포넌트 태그 사이의 요소는 props.children으로 전달됨
 */

function Greeting({ name = "기본이름", favoriteNumber = "1", children }) {
    return (
        <>
            <h1>안녕하세요, {name}님!</h1>
            <h2>제가 좋아하는 숫자는 {favoriteNumber}</h2>
            <strong>전달된 자식 요소(children): {children}</strong>
        </>
    );
}

function App() {
    const name1 = "홍길동";
    const name2 = "유관순";

    return (
        <>
            {/* 태그 사이에 전달한 콘텐츠가 children 속성으로 전달됨 */}
            <Greeting name={name1} favoriteNumber={5}>
                props 공부 중!
            </Greeting>
            <Greeting name={name2} favoriteNumber={7}>
                <div>여러 줄도 가능</div>
                <div>React</div>
            </Greeting>
            {/* Props 미전달 시 설정한 기본값이 출력됨 */}
            <Greeting />
        </>
    );
}

const root = ReactDOM.createRoot(document.getElementById("root"));
root.render(<App />);

```

## 느낀 점
* 기존 `React.createElement` 방식의 복잡했던 중첩 구조를 JSX 문법을 통해 HTML과 유사하고 직관적인 선언형 UI 코드로 작성할 수 있게 되어 생산성과 가독성이 크게 향상됨을 확인함
* HTML 문법과 유사해 보이지만 `className`, `onClick`과 같은 속성명 표기법 차이와 인라인 스타일을 객체 형태로 넘겨야 하는 등 JSX 특유의 자바스크립트 기반 제약 규칙을 명확히 숙지함
* React의 핵심 구조인 Props를 사용하여 부모-자식 간 데이터 흐름을 형성하고, ES6 구조 분해 할당과 `children` 속성을 활용해 유연하고 재사용성 높은 컴포넌트 구조를 설계하는 패턴을 파악함
