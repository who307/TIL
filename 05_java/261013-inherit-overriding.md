# Java 객체지향 프로그래밍 핵심 정리 (TIL)

## 1. 상속 (Inheritance)과 `super` 키워드

* **상속(Inheritance)의 개념**: `Car`와 `FireCar` 클래스 예시를 통해 기존 클래스의 자산을 물려받아 새로운 기능을 확장하는 상속 메커니즘을 습득함.


* **`super` 키워드 활용**: 부모 클래스의 멤버나 생성자에 접근하기 위해 `super` 키워드를 사용하는 구조를 `Product`, `Computer`, `SmartPhone` 클래스를 통해 파악함.



---

## 2. 메소드 오버라이딩 (Method Overriding)

* **오버라이딩 개념**: 부모 클래스로부터 상속받은 메소드를 자식 클래스에서 자신만의 목적에 맞게 재정의(Overriding)하여 사용하는 기법을 이해함.


* **자판기 예시 적용**: `VendingMachine`과 `CoffeeVendingMachine` 클래스를 통해 상속 관계에서의 메소드 재정의 동작 방식을 체득함.



---

## 3. 다형성 (Polymorphism)

* **다형성(Polymorphism)의 정의**: 상속 관계에 있는 타입 간의 형변환을 통해 하나의 부모 타입으로 여러 자식 객체를 유연하게 다룰 수 있는 성질을 학습함.


* **동작 구조**: `Animal`, `Rabbit`, `Tiger`, 그리고 이들을 관리하는 `Zookeeper` 클래스를 활용해 다형적 객체 조작 및 동적 바인딩의 원리를 파악함.



---

## 4. 추상 클래스 (Abstract Class)

* **추상 클래스 선언**: 미완성 상태의 `abstract` 키워드를 활용해 공통된 특성을 정의하고, 자식 클래스에게 구체적인 메소드 구현을 강제하는 추상 클래스의 구조를 이해함.



---

## 느낀 점

* 상속과 `super` 키워드를 통해 코드의 중복을 줄이고 클래스 간의 계층적 구조를 명확히 구축하는 방식을 체득함.


* 메소드 오버라이딩을 활용하여 자식 클래스에서 상황에 맞게 기능을 유연하게 변경하는 방법을 파악함.


* 다형성과 추상 클래스를 다루며 객체지향 설계의 확장성과 유연성을 높이는 핵심 패턴을 이해함.
