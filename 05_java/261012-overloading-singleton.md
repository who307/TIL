# Java 핵심 기술 정리 (TIL)

## 1. 변수의 종류 (Kinds of Variables)

* 클래스 영역에 선언되는 인스턴스 변수 및 정적(static) 클래스 변수의 개념을 파악함.


* 메소드 내부 또는 블록 내에 선언되어 해당 영역에서만 유효한 지역 변수와 매개변수의 생명주기 차이를 체득함.



---

## 2. 메소드 오버로딩 (Method Overloading) 및 매개변수 (Parameters)

* **메소드 오버로딩 규칙**: 동일한 클래스 내에서 메소드 이름이 같더라도 매개변수의 개수, 타입, 순서가 다르면 다중 정의할 수 있는 오버로딩 규칙을 학습함.


* **매개변수 전달 방식**: 기본 자료형, 배열, 객체 참조 자료형, 그리고 개수가 정해지지 않은 가변 인자(Variable Arguments)가 메소드 인자로 전달되는 방식을 파악함.



---

## 3. `static` 키워드와 `final` 키워드

* **`static` 키워드**: 인스턴스 생성 없이 클래스 레벨에서 공유되는 변수와 메소드의 특징을 `Student` 클래스를 통해 이해함.


* **`final` 키워드**: 변수 값 변경 금지, 메소드 오버라이딩 제한, 상속 금지 등 `final`이 적용되는 위치별 제약 사항과 `MathConstant` 구현 방식을 체득함.



---

## 4. 싱글톤 패턴 (Singleton Pattern)

* **싱글톤의 개념**: 메모리 낭비를 방지하고 단 하나의 인스턴스만 생성하여 전역에서 공유하도록 설계하는 디자인 패턴을 학습함.


* **Eager vs Lazy 초기화**: 프로그램 시작 시점에 미리 인스턴스를 생성하는 이른 초기화(`EagerSingleton`)와 최초 호출 시점에 인스턴스를 생성하는 게으른 초기화(`LazySingleton`)의 구현 방식을 비교·파악함.



---

## 느낀 점

* 변수의 선언 위치에 따른 종류와 생명주기를 구분하고, 다형성을 지원하는 메소드 오버로딩의 규칙을 명확히 정리함.


* `static`과 `final`을 통해 메모리 공유와 불변성 제어를 구현하는 자바의 핵심 제어자를 다뤄봄.


* 싱글톤 패턴의 두 가지 구현 방식(Eager, Lazy)을 통해 객체 생성 제어와 메모리 효율성 최적화 기법을 체득함.
