# Java 핵심 기술 정리 (TIL)

## 1. 자바 기본 문법 (리터럴, 변수, 상수, 오버플로우, 형변환)

### 리터럴(Literal) 및 연산 규칙

* 정수, 실수, 문자(`'a'`), 문자열(`"abc"`), 논리값(`true`/`false`) 등의 기본 표기법을 구별함.


* 정수와 실수의 산술 연산 시 정수가 실수로 자동 변환되어 연산되며, 문자(`char`) 연산 시 아스키코드 정수 값으로 계산되는 특성을 체득함.


* 문자열과의 `+` 연산은 결합 연산자로 동작하며, 다른 자료형도 문자열로 취급되어 연결되는 결합 규칙을 습득함.



### 변수(Variable)와 명명 규칙

* 메모리 공간을 확보하기 위한 기본 자료형 8가지(`byte`, `short`, `int`, `long`, `float`, `double`, `char`, `boolean`)와 참조 자료형(`String`)의 용량 및 선언법을 정리함.


* 동일 스코프 내 중복 선언 불가, 예약어 사용 불가, 대소문자 구분, 숫자로 시작 불가 등 문법적 제약과 낙타표기법(CamelCase), 긍정 의문문 형식(`isAlive`) 등 명명 관례를 파악함.



### 상수(Constant)

* `final` 키워드를 선언하여 한 번 초기화된 변수의 값을 변경할 수 없도록 고정하는 상수의 개념과 작성법을 작성함.



### 오버플로우(Overflow) 및 언더플로우(Underflow)

* 고정된 메모리 크기를 갖는 정수형 데이터 타입이 표현 범위를 초과할 경우 발생하며, 최대값을 넘어서면 최소값으로 순환하는 오버플로우 및 반대 현상인 언더플로우의 동작 원리를 이해함.



### 형변환(Typecasting)

* **자동 형변환(Implicit Casting)**: 작은 크기의 자료형에서 큰 크기의 자료형으로, 또는 정수형에서 실수형으로 데이터 손실 없이 자동으로 변환되는 흐름을 습득함.


* **강제 형변환(Explicit Casting)**: 데이터 손실(Truncation) 위험을 감수하고 데이터 타입을 변환할 때, 형변환 연산자 `(자료형)`을 명시적으로 지정하는 다운캐스팅 기법을 체득함.

## 2. 연산자 (Operators)

### 산술·비교·논리·대입 연산자

* 기본 사칙연산(`+`, `-`, `*`, `/`, `%`)의 동작과 정수 나누기 시 소수점 절삭 특성을 확인함.


* 관계 연산자(`>`, `<`, `==`, `!=`)를 통한 조건 평가 결과가 논리형(`boolean`)으로 반환되는 구조를 습득함.


* Short-Circuit Evaluation(단락 평가)이 적용되는 논리 연산자(`&&`, `||`, `!`) 및 복합 대입 연산자(`+=`, `-=` 등)의 효율적인 사용법을 파악함.



### 증감 연산자 및 삼항 연산자

* 전위 증감 연산자(`++count`)와 후위 증감 연산자(`count++`)의 평가 시점에 따른 값의 차이를 구별함.


* `조건식 ? 참일 때 값 : 거짓일 때 값` 형태의 삼항 연산자를 활용하여 가독성 높은 조건 분기 코드를 작성하는 기법을 체득함.

## 3. 메소드 (Method) 및 패키지/임포트 (Package & Import)

### 메소드 정의 및 호출 구조

* 반복 코드를 줄이고 모듈화하기 위해 매개변수(Parameter)와 반환값(Return Value)을 선언하여 메소드를 호출하는 흐름을 파악함.


* `void` 키워드를 통한 반환값 없는 메소드 처리 및 `return` 구문을 이용한 데이터 반환 메커니즘을 습득함.



### 인스턴스 생성과 연산 분리

* `new` 키워드를 사용하여 객체(Instance)를 생성한 뒤 non-static 메소드를 참조 연산자(`.`)로 호출하는 구조를 체득함.


* 연산 담당 클래스(`Calculator`)를 별도로 설계하고 메인 로직에서 인스턴스를 통해 호출하는 클래스 간 분리 구조를 이해함.



### 패키지(Package)와 임포트(Import)

* 클래스의 중복을 방지하고 계층적으로 관리하기 위한 패키지의 역할과 풀 패키지 명(Fully Qualified Name) 작성법을 습득함.


* 다른 패키지의 클래스를 사용할 때 `import` 구문을 작성하여 코드의 간결성을 유지하는 선언 방식을 파악함.

## 느낀 점

* 리터럴과 기본 데이터 타입의 연산 우선순위 및 자동/강제 형변환 메커니즘을 복습하면서 자바 메모리 구조 내에서 정수 및 실수형이 어떻게 다뤄지는지 명확히 파악함.


* 오버플로우와 언더플로우 현상을 확인하며 적절한 데이터 타입 선택이 시스템 안정성과 직결된다는 점을 깨달음.


* 산술, 논리, 삼항 연산자의 특성과 전위/후위 증감 연산자의 시점 차이를 구분하여 조건 처리 코드를 더욱 간결하고 안전하게 작성하는 테크닉을 습득함.


* 단순히 코드 블록을 나열하는 방식에서 벗어나, 기능별로 메소드를 분리하고 인스턴스화하여 호출하는 클래스 분리 설계 및 패키지 관리의 중요성을 확인함.
