## 핵심 내용(코드)
- git init 기본 셋팅
- git add 변경한 파일 스테이징
- git commit -m "내용" 변경 내용 메세지 입력
- git branch branchname 브랜치 생성
- git switch branchname 브랜치 이동
- git switch -c branchname 브랜치 생성후 이동
- git push origin main 원격저장소에 main 브랜치 변경 내용 push
- git merge branchname 브랜치 병합 merge
- git log 깃 로그 내용
- git log --oneline 깃 로그 한줄
